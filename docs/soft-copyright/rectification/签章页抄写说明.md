# 申请确认签章页抄写说明

本说明用于处理《软件登记补正通知书》中“申请确认签章页未抄写划线部分内容”的问题。

## 操作步骤

1. 登录中国版权保护中心系统，进入对应流水号 `2026R11L1225249` 的申请记录。
2. 下载或重新打印系统生成的“申请确认签章页”。
3. 找到签章页中要求申请人抄写的划线部分文字。
4. 由申请人本人使用黑色签字笔，在指定位置逐字手写抄写划线部分内容。
5. 在申请人签名/签章处签署“何旻洋”。
6. 填写签署日期，建议与补正提交日期保持一致或填写实际签署日期。
7. 将处理后的签章页扫描或拍照上传，确保页面完整、清晰、无裁切、无遮挡。

## 注意事项

1. 划线内容以版权中心系统生成页面为准，不要参考他人模板自行改写。
2. 手写内容应完整覆盖划线要求，不要只签名不抄写。
3. 不要使用打印文字替代手写抄写。
4. 不要涂改申请人姓名、软件名称、流水号等关键信息。
5. 如果签章页重新生成后文字内容变化，以最新生成页面为准。
